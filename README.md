# Sync Guild Pruner

## - A Python project exploring Discord guild management concepts and terminal-based automation.

# Features

- RGB gradient terminal banner
- Configurable guild ID
- Role-related configuration options
- Confirmation prompt before an operation
- Basic guild and permission checks
- Operation result output

# Requirements

- Python 3
- "discord.py-self"
- Required Python dependencies

# Installation
- `cd Sync-Server-Pruner`
- `python main.py`

Review the source code and configure the required settings before running the project.

# Configuration

Update the configuration values in "main.py" as needed for your environment.

Never publish Discord account tokens, bot tokens, passwords, or other sensitive credentials in a public repository.
